netkuma.js

A lightweight, low-level Node.js networking framework built on top of raw TCP, inspired by real server internals, and API (mainly Fastify) and designed as a learning project to understand request handling, routing, protocol parsing, and deployment from scratch.

`net` in netkuma is a small nudge to the `net` module in Node.js. I was experimenting with that when the idea came to me.
View on GitHub Docs
netkuma.js currently powers its own production deployment, (including this site!), demonstrating a fully custom stack from TCP socket to browser.
Tools used: Node.js net sockets, Linux, systemd services, Nginx reverse-proxy, Certbot for TLS, and a self-managed VPS.
